# LeetCode Python DSA Journey 🚀

My personal DSA technique handbook and Python solution library for coding interview preparation.

Each topic has a dedicated folder containing technique explanations, problem-solving approaches, related LeetCode questions, Python solutions, and key learnings.

## 📚 Master DSA Roadmap

### Fundamentals & Array Patterns

- **01. Arrays & Hashing**
  - Hash maps, hash sets, and frequency counting
  - Duplicate detection and grouping
  - Lookup optimization and in-place array operations

- **02. Two Pointers**
  - Opposite-direction pointers
  - Same-direction pointers
  - Fast & slow pointers
  - Two pointers combined with sorting
  - Two pointers on strings and linked lists

- **03. Sliding Window**
  - Fixed-size window
  - Variable-size window
  - Frequency-map window
  - Longest/shortest valid subarray or substring

- **04. Prefix Sum & Difference Arrays**
  - Prefix and suffix sums
  - Prefix sum + hashmap
  - Range sum queries
  - 2D prefix sums and difference arrays

- **05. Binary Search**
  - Classic binary search
  - First/last occurrence and boundary search
  - Rotated sorted arrays
  - Binary search on answer

- **06. Sorting & Intervals**
  - Sorting and custom sort keys
  - Merge intervals
  - Interval scheduling and meeting rooms
  - Sweep-line techniques

- **07. Strings & String Algorithms**
  - Palindromes and anagrams
  - Character counting and string parsing
  - String manipulation and matching
  - Advanced matching: KMP and rolling hash

### Core Data Structures

- **08. Linked Lists**
  - Reversal and merging
  - Fast & slow pointers and cycle detection
  - Middle node and intersection
  - Reordering and dummy-node techniques

- **09. Stacks, Queues & Monotonic Structures**
  - Stack and queue fundamentals
  - Parentheses and expression evaluation
  - Monotonic increasing/decreasing stack
  - Monotonic deque

- **10. Trees & Binary Search Trees**
  - DFS traversals: preorder, inorder, postorder
  - BFS and level-order traversal
  - BST operations and validation
  - Tree paths, diameter, and lowest common ancestor
  - Tree construction and recursion

- **11. Heaps & Priority Queues**
  - Min-heap and max-heap
  - Top K elements
  - K-way merge
  - Two heaps and priority-based scheduling

- **12. Matrices & Grid Problems**
  - Matrix traversal and transformations
  - Spiral traversal and rotation
  - Grid DFS and BFS
  - Multi-source BFS

### Core Algorithms

- **13. Recursion & Backtracking**
  - Recursion and base cases
  - Subsets and combinations
  - Permutations
  - Grid search and constraint problems
  - Pruning and decision trees

- **14. Graphs**
  - Graph representation and traversal
  - DFS, BFS, connected components, and cycle detection
  - Topological sorting
  - Shortest paths: BFS, Dijkstra, Bellman-Ford
  - Union-Find / Disjoint Set Union

- **15. Dynamic Programming**
  - Memoization and tabulation
  - 1D DP
  - 2D DP and grid problems
  - Knapsack and subset sum
  - Subsequences: LIS and related problems
  - String DP: LCS and edit distance
  - State-machine and interval DP

- **16. Greedy Algorithms**
  - Interval-based greedy
  - Jump games
  - Sorting-based greedy
  - Heap-based greedy
  - Greedy choice and correctness reasoning
